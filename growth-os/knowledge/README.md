# NiwasNest knowledge base

Every agent reads from here, nowhere else. Each file has front-matter:

- `authority`: 1 founder policy · 2 admin commercial settings · 3 verified product facts · 4 approved scripts · 5 historical ideas (never quoted)
- `approved: true|false`: unapproved files are invisible to agents.

To change what the AI says, edit a file here and get it reviewed. Do not put numbers
(commission, rewards, discounts) in scripts: agents fetch them from the policy engine.
